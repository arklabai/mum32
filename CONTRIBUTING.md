# Contributing to mum32

We welcome contributions to **mum32** — *Memory for your AI Harness & Coding Agents*!

Please read our full contributing guidelines located in:
👉 **[.github/CONTRIBUTING.md](.github/CONTRIBUTING.md)**

### Quick Reference:
- **Dev Mode**: `npm run dev` (runs webview Vite watcher + extension TypeScript compiler)
- **Run Tests**: `npm test`
- **Build All**: `npm run compile`
- **Bug Reports**: Please use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md)
- **Feature Requests**: Please use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md)
